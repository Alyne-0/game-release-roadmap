# Серверная часть сервиса планирования контента и дорожной карты релизов игры

Сервис предназначен для планирования игровых релизов и распределения контента между ними. Дорожная карта показывает версии, плановые даты и статусы релизов.

## Текущее состояние

API позволяет создавать и редактировать релизы, менять их статус и просматривать дорожную карту в порядке плановых дат. Релизы хранятся в файловой SQL-базе H2. При первом запуске Flyway создаёт таблицу и добавляет два демонстрационных релиза.

Стек проекта — Java 17, Spring Boot (Spring MVC и JDBC), Maven, H2 и Flyway.

## Запуск

Требуется JDK 17 или новее. Maven Wrapper скачает Maven при первом запуске.

```sh
./mvnw spring-boot:run
```

В Windows PowerShell команда запуска — `.\mvnw.cmd spring-boot:run`.

Файл базы `data/roadmap.mv.db` создаётся в рабочем каталоге и сохраняется между запусками.

## API релизов

| Метод и путь | Результат |
| --- | --- |
| `GET /api/releases` | Список релизов по плановой дате |
| `GET /api/releases/{version}` | Релиз по версии или `404 Not Found` |
| `POST /api/releases` | Новый релиз со статусом `PLANNED`, ответ `201 Created` и ссылка на релиз в заголовке `Location` |
| `PUT /api/releases/{version}` | Обновлённый релиз с ответом `200 OK` или `404 Not Found` для отсутствующей версии |

При создании обязательны версия (три числа через точку, до 32 символов), непустое название до 120 символов и плановая дата в формате `YYYY-MM-DD`. Для неверных данных сервер возвращает `400 Bad Request`, для повторной версии — `409 Conflict`.

```sh
curl -i http://localhost:8080/api/releases \
  -H 'Content-Type: application/json' \
  -d '{"version":"0.3.0","title":"Обновление карты","plannedDate":"2027-06-10"}'

curl http://localhost:8080/api/releases
```

При редактировании укажите версию в URL, а в JSON передайте название, плановую дату и статус. Допустимые статусы — `PLANNED`, `IN_PROGRESS` и `RELEASED`. После переноса даты релиз занимает соответствующее место в дорожной карте.

```sh
curl -i -X PUT http://localhost:8080/api/releases/0.3.0 \
  -H 'Content-Type: application/json' \
  -d '{"title":"Обновление карты и заданий","plannedDate":"2027-06-24","status":"IN_PROGRESS"}'
```
