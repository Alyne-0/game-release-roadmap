# Серверная часть сервиса планирования контента и дорожной карты релизов игры

Сервис предназначен для планирования игровых релизов и распределения контента между ними. Дорожная карта показывает версии, плановые даты и статусы релизов.

## Текущее состояние

Реализован первый маршрут REST API. `GET /api/releases` возвращает два демонстрационных релиза в JSON. Данные заданы в сервисе и доступны для чтения.

Стек проекта — Java 17, Spring Boot (Spring MVC) и Maven.

## Запуск

Требуется JDK 17 или новее. Maven Wrapper скачает Maven при первом запуске.

```sh
./mvnw spring-boot:run
```

В Windows PowerShell команда запуска — `.\mvnw.cmd spring-boot:run`.

После запуска список релизов доступен по адресу:

```sh
curl http://localhost:8080/api/releases
```
